# 💰 Smart Personal Expense Analyzer

An end-to-end data science project that analyzes personal finance data, predicts monthly expenses using machine learning, and delivers budget insights through an interactive Gradio web app.

## Overview

This project applies a full data science workflow — from raw messy data to a deployed interactive dashboard — on a personal finance dataset. It covers data cleaning, statistical analysis, visualization, feature engineering, supervised learning, unsupervised clustering, and association rule mining. The final deliverable is a Gradio UI where users can enter their financial profile and receive real-time expense predictions and budget recommendations.

---

## Features

- **Data Preprocessing** — duplicate removal, missing value imputation (median/mode), IQR-based outlier winsorizing, categorical standardization
- **Exploratory Data Analysis** — descriptive statistics, histograms, boxplots, scatter plots, correlation heatmap, pairplot
- **Feature Engineering** — label encoding, min-max / standard scaling, derived financial ratios
- **Supervised Learning**
  - Linear Regression — predicts `monthly_expense_total`
  - Logistic Regression — classifies whether a savings goal will be met
- **Unsupervised Learning** — Agglomerative Hierarchical Clustering with dendrogram visualization
- **Association Rule Mining** — Apriori algorithm to find co-occurring spending patterns
- **Interactive Gradio App** — dark-themed UI with sliders, dropdowns, spending insights, and two dynamic charts
  - 6-month simulated income vs. expense trend
  - Category-wise spending breakdown (donut chart + benchmark bar chart)

## Usage

### Step 1 — Run the analysis notebook

Open `Smart Personal Expense Analyzer.ipynb` in Jupyter or Google Colab and run all cells. This will:

- Load and clean `personal_finance_tracker.csv`
- Generate all plots and CSV summaries inside `outputs/`
- Train and save the ML models (`.pkl` files) to `outputs/`

### Step 2 — Launch the Gradio app

```bash
python gradio_expense_analyzer (1) (1).py
```

Or in Colab, paste at the end of a cell:

```python
demo.launch(share=True)
```

Gradio will print a public link (e.g. `https://xxxxx.gradio.live`). Open it in any browser.

### Step 3 — Analyze your expenses

Fill in your financial profile using the sliders and dropdowns, then click **🔍 Analyze My Expenses** to see:

- Predicted monthly expense
- Monthly surplus / deficit
- Savings goal prediction with confidence
- 6-month simulated trend chart
- Category spending breakdown vs. benchmarks

## ML Pipeline

```
Raw CSV
  └─► Data Cleaning (dedup, impute, winsorize, standardize)
        └─► EDA (stats, histograms, scatter, heatmap)
              └─► Feature Engineering (encoding, scaling)
                    ├─► Linear Regression  →  Predict monthly_expense_total
                    ├─► Logistic Regression →  Classify savings_goal_met
                    ├─► Apriori            →  Find spending pattern rules
                    └─► Agglomerative Clustering  →  Segment user profiles
                              └─► Saved .pkl models
                                    └─► Gradio UI (real-time inference)
```

**Key features used for prediction:**

`monthly_income`, `savings_rate`, `credit_score`, `debt_to_income_ratio`, `loan_payment`, `investment_amount`, `discretionary_spending`, `essential_spending`, `transaction_count`, `income_type`, `financial_scenario`, `financial_stress_level`

## Dataset

The dataset (`personal_finance_tracker.csv`) contains anonymized personal finance records with the following key columns:

date, user_id, monthly_income, monthly_expense_total, savings_rate, budget_goal, financial_scenario, credit_score, debt_to_income_ratio, loan_payment, investment_amount, subscription_services, emergency_fund, transaction_count, fraud_flag, discretionary_spending, essential_spending, income_type, rent_or_mortgage, category, cash_flow_status, financial_advice_score, financial_stress_level, actual_savings, savings_goal_met

Dataset size (3,010 records)
Number of features (25)
Missing values handled (3,759)

The raw data intentionally contains missing values, duplicates, inconsistent categories, and outliers — addressing these is part of the practical exercises.
